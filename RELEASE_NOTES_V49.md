# Release 49 — Correção dos campos personalizados

## Correções

- Reorganiza o checkbox **Obrigatório**, os botões de ordenação e o botão **Remover**, evitando sobreposição.
- Mantém o foco e a posição do cursor ao digitar no campo de orientação (placeholder).
- Melhora o comportamento responsivo do editor de campos personalizados.
- Ajusta o foco inicial ao adicionar um novo campo.

## Banco de dados

Esta versão não possui nova migração de banco. Quem já executou a versão 48 não precisa executar SQL novamente.
