# Versão 59

## Ajustes

- Projetos inativos, em rascunho ou arquivados deixaram de aparecer nos filtros do Kanban, histórico e indicadores.
- Adicionada a ação **Duplicar solicitação** na tela de detalhes.
- A duplicação cria uma nova solicitação preenchida para revisão, mantendo os dados do formulário, projeto, grupo e prioridade.
- Histórico, comentários, status, responsável, anexos e controle de cancelamento no CRM não são copiados.
- Atualizado o cache do aplicativo para garantir a entrega da nova versão após a publicação.
